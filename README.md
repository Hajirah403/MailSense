# MailSense

AI-powered Gmail assistant that automatically reads, classifies, and drafts replies to emails using Retrieval-Augmented Generation (RAG) and a fine-tuned DistilBERT model.

Developed as a team Final Year Project at Government College University (GCU), Lahore.

## Features

- Automated email reading and classification using a fine-tuned DistilBERT model
- RAG-based context retrieval for generating relevant email replies
- Semantic search over email history using ChromaDB
- Google OAuth2 integration for secure Gmail access
- REST API backend built with FastAPI
- React-based frontend interface

## Tech Stack

**Backend:** Python, FastAPI, SQLAlchemy, ChromaDB
**Machine Learning:** Fine-tuned DistilBERT, sentence embeddings, RAG pipeline
**Frontend:** React
**Auth:** Google OAuth2
